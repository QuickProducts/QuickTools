## QuickTools 0.4.2 preview

Радиальное меню быстрых действий для Windows 10/11 x64.

- Собственный установщик, пошаговая загрузка компонентов и интерактивное знакомство.
- Стеклянное оформление, настройки и контекстные страницы форматов.
- Исправлен маршрут MP4 → WebM: VP9/Opus, проверка потоков и результата через ffprobe.
- Безопасное сохранение без перезаписи, резервная папка при запрете записи.
- История задач и диагностика ошибок; ввод без глобальных low-level hooks.

Скачайте **QuickToolsSetup.exe**. .NET включён; выбранные движки загружаются при первом запуске. **SHA256SUMS.txt** содержит контрольную сумму установщика.

Предварительная, неподписанная сборка. Ограничения форматов и инструкция: https://github.com/QuickProducts/QuickTools/wiki

TXT → BAT и подобные действия копируют текст с другим расширением; они не создают программный код. Обработка файлов выполняется локально.
