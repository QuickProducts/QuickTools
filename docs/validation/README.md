# Проверка 0.4.2

Локальный прогон на Windows x64. Сводка без локальных имён пользователя и путей машины разработчика.

| Набор | Проверка | Результат |
|---|---|---|
| Media | Обычный MP4, нечётные размеры, видео без аудио, звук 5.1 | 17 преобразований пройдено |
| Negative | Недоступное назначение, отсутствие аудио | 2 пройдено |
| Images | PNG → PNG/JPG/WebP/ICO/PDF/AVIF/BMP/TIFF/GIF/TGA/PPM | 11 пройдено |
| Documents | MD → DOCX → TXT/HTML/EPUB/RTF/ODT/PDF; кириллица через PDF → текст | Пройдено |
| Storage | ZIP/TAR/GZIP, SHA-256, коллизии имён, кириллица, текстовые копии, сохранность исходника | Пройдено |
| UI | 16 открытий настоящего меню с анимацией и без; первый запуск и окно результатов | Пройдено |
| DPI / Shell | Расчёт 100/150/200/300%, ограниченный worker, последовательность мастера | Пройдено |
| Setup | SHA-256 payload, runtime, распаковка, защита занятой папки | Пройдено |

Медиа полностью декодировались после конвертации. Для WebM дополнительно проверялись кодеки, звук, размер кадра и длительность. Для JPG проверялся белый фон, для ICO — квадратный холст.

## Границы

Синтетические входы не покрывают все кодеки, HDR, повреждённые файлы и метаданные. Реальный Ctrl над файлами Explorer, несколько вкладок, несколько мониторов, ярлыки и удаление не входят в подтверждённый сквозной UI-прогон.

Команды повторения — в [Development](../wiki/Development.md). Сырые журналы и тестовые медиа исключены из git, поскольку могут содержать локальные пути.
