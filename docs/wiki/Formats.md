# Форматы и ограничения

| Источник | Действия | Движок |
|---|---|---|
| Видео: MP4, MKV, MOV, AVI, WebM, TS и другие | MP4, WebM, MKV, MOV, AVI, GIF, MPEG, TS, кадр PNG; извлечение MP3/WAV/FLAC/AAC | FFmpeg + ffprobe |
| Аудио: MP3, WAV, FLAC, OGG, AAC, Opus и другие | MP3, WAV, AAC/M4A, FLAC, Opus, OGG, AIFF, WMA, AC3 | FFmpeg |
| Изображения: PNG, JPEG, WebP, TIFF, GIF и другие | PNG, JPG, WebP, ICO, PDF, AVIF, BMP, TIFF, GIF, TGA, PPM | ImageMagick |
| Документы: DOCX, ODT, RTF, EPUB и другие поддерживаемые Pandoc | PDF, DOCX, ODT, RTF, TXT, Markdown, HTML, EPUB, LaTeX, Org, RST, PPTX | Pandoc; PDF через Typst |
| PDF | Текст, PNG/JPG первой страницы | Poppler |
| Текст и исходный код | Копия с расширением BAT, CMD, PS1, PY, JS, JSON, CSV и другими; UTF-8 | Встроенные действия |
| Любые файлы | ZIP, TAR, GZIP, SHA-256, копирование путей | Встроенные действия |

## Что важно знать

- **TXT → BAT — копия байтов с другим расширением.** QuickTools не пишет команды и не переводит языки программирования.
- WebM кодируется VP9/Opus; MP4 — H.264/AAC. Это настоящее перекодирование, поэтому скорость зависит от длительности, процессора и формата.
- Для совместимости используются yuv420p и дополнение нечётных размеров кадра. Обрабатываются основные видео- и аудиодорожки, без обещания переноса всех потоков и метаданных.
- При конвертации изображений используется первый кадр; JPG получает белый фон вместо прозрачности. ICO ограничивается 256×256.
- PDF → текст не выполняет OCR. Скан без текстового слоя может не дать текста.
- Pandoc не заменяет офисный пакет: старый DOC, XLS/XLSX и входной PPT/PPTX не поддерживаются этим маршрутом. Наличие категории файла не означает наличие офисной конвертации. PPTX доступен как выходной формат Pandoc.
- HEIC, JXL, SVG, PSD и другие сложные изображения зависят от возможностей установленной сборки ImageMagick и её делегатов.

Результат обычно сохраняется рядом с исходником с `_converted`. Существующие файлы не перезаписываются: выбирается свободное имя. При запрете записи используется `%LOCALAPPDATA%\QuickTools\Converted`; точный путь виден в истории. Неудачная конвертация не должна оставлять пустой итоговый файл.
