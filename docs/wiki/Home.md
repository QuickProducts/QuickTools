# QuickTools Wiki

![QuickTools](https://raw.githubusercontent.com/QuickProducts/QuickTools/main/assets/quicktools-banner-glass.png)

**Быстрые действия для файлов — прямо вокруг курсора.**

QuickTools — фоновая утилита Windows с круговым меню, локальной конвертацией и собственным установщиком. Текущая версия: **0.4.2 preview**.

Конвертация выполняется на компьютере. Для первоначальной загрузки выбранных движков нужен интернет. Это предварительная версия: неподдерживаемые документы, DRM и повреждённые файлы могут не конвертироваться.
