# Установка

Требуется Windows 10/11 x64. Скачайте **QuickToolsSetup.exe** из [релиза 0.4.2](https://github.com/QuickProducts/QuickTools/releases/tag/v0.4.2).

1. Откройте собственный установщик QuickTools и выберите папку.
2. Дождитесь распаковки приложения. .NET входит в поставку.
3. При первом запуске выберите необходимые движки: FFmpeg, ImageMagick, Pandoc, Typst и Poppler.
4. Дождитесь загрузки и проверки SHA-256, затем пройдите интерактивное знакомство.

WinGet и LibreOffice не требуются. Компоненты загружаются прямыми ссылками; проверка контрольной суммы не заменяет цифровую подпись приложения. Текущая сборка не подписана.

## Обновление

Завершите QuickTools через трей и запустите новый установщик. Не заменяйте файлы работающего приложения.

## Где находятся данные

| Данные | Папка |
|---|---|
| Приложение | Выбранная при установке папка |
| Настройки | `%LOCALAPPDATA%\QuickTools\settings.json` |
| Движки | `%LOCALAPPDATA%\QuickTools\tools` |
| Временные результаты | `%LOCALAPPDATA%\QuickTools\work` |
| Резервная папка результатов | `%LOCALAPPDATA%\QuickTools\Converted` |
| История | `%LOCALAPPDATA%\QuickTools\conversions.jsonl` |

Настройки и движки могут оставаться после удаления приложения. История и журналы содержат локальные пути: удаляйте личные сведения перед публикацией.
