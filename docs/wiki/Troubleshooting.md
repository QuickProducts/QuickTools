# Решение проблем

## Результат не появился рядом с файлом

Откройте трей → **«Задачи и результаты»**. Если исходная папка недоступна для записи, результат находится в `%LOCALAPPDATA%\QuickTools\Converted`.

Различайте запрет чтения исходника, запрет записи результата и запрет запуска движка. Для файла OneDrive сначала дождитесь локальной загрузки. Закройте программы, удерживающие файл. Проверьте доступ на собственном обычном файле в папке пользователя. Не отключайте защиту Windows и не запускайте всё от администратора в качестве универсального исправления.

## MP4 → WebM выдаёт ошибку или нет звука

Проверьте наличие FFmpeg **и ffprobe** через настройки компонентов. Для WebM используются VP9 и Opus; переименование расширения недостаточно. У исходного видео может не быть аудиодорожки. Повреждённый файл, DRM или неподдерживаемый кодек приводят к ошибке — подробность записывается в историю и runtime-журнал.

## Ctrl не открывает меню

Нужен активный Проводник или рабочий стол. Попробуйте выделить файл и нажать Ctrl + Space. Проверьте конфликт сочетания с другой программой. Некоторые виртуальные папки и нестандартные расширения оболочки не предоставляют обычный путь к файлу.

Запрос Shell изолирован и ограничен тайм-аутом 1,8 секунды. Приложение не использует глобальные низкоуровневые хуки. Если зависание повторяется, завершите QuickTools через трей и приложите сведения о версии Windows и типе папки.

## Как сообщить об ошибке

Укажите версию QuickTools, исходный и целевой формат, шаги, ожидаемый результат и точный текст ошибки. По возможности приложите небольшой несекретный пример. Перед публикацией журналов удалите имя пользователя, личные пути и содержимое документов.

Для обновления сначала закройте приложение через трей. Ограничения форматов перечислены на странице [Formats](Formats).
